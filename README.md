# FitLog — Workout Library & Daily Planner

A modern, responsive fitness logging web application built with Next.js, React, and Tailwind CSS. FitLog allows fitness enthusiasts to browse workouts, view detailed exercise execution guides, and curate their daily training routine with real-time metric tracking.

## 🚀 Technologies Used

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS & DaisyUI
- **Icons:** React Icons
- **Notifications:** React Toastify
- **State Management:** React Context API

## ✨ Key Features

1. **Dynamic Workout Library:** Comprehensive exercise directory featuring equipment filters, targeted muscle tags, duration, and calories burned.
2. **Interactive Daily Log (My Plan):** Dual-view management system allowing users to switch seamlessly between "Today's Plan" and "Saved" workouts.
3. **Live Metrics Calculator:** Real-time automatic recalculation of total exercises, training minutes, and calories burned using functional array reducers.
4. **Custom List Sorting:** Multi-criteria sorting allowing users to order workouts dynamically by duration, calories, or community ratings.
5. **Workout Completion & Tracking:** Quick actions to mark workouts as completed with success feedback toasts and responsive removal handlers.
